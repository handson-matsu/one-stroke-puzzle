# ひとふで — One Stroke Puzzle

ブラウザで遊べる、点と線の一筆書きパズルです。HTML・CSS・JavaScriptのみで作成し、外部ライブラリ、フォント、ビルド処理は使用していません。

## 遊び方

1. 好きな頂点を選んでスタートします。
2. 線でつながった隣の頂点をクリック／タップして進みます。マウスや指を押したまま、頂点を順になぞっても移動できます。途中で指を離しても続けられます。
3. 同じ辺は2回通れません。頂点には何度でも戻れます。
4. すべての辺をちょうど1回通ればクリア。「次のステージ」で先に進みます。

緑色の線は通過済み、金色の点は現在地です。線の交差部分には頂点はなく、曲がれるのは番号付きの点だけです。行き止まりになったら「やり直す」で出発点や順番を変えてみてください。開始位置によってはクリアできないステージもあります。

三角形から複雑な格子まで全5ステージ。最後までクリアすると「もう一度あそぶ」で最初に戻れます。キーボードでは Tab で頂点へ移動し、Enter またはスペースで選択できます。進行状況は保存されず、再読み込みで最初に戻ります。

## 起動

`index.html` をブラウザで開くだけで遊べます。MacのマウスとiPhone／iPadのタッチに対応した Pointer Events を使用しています。スマートフォン・タブレット・PCの画面幅に合わせて表示が変わります。

## GitHub Pagesで公開

1. この3つのアプリファイルとREADMEをリポジトリのルートに配置して、GitHubへpushします。
2. リポジトリの **Settings → Pages** を開きます。
3. **Deploy from a branch** を選択し、`main` ブランチと `/ (root)` を指定して保存します。
4. 公開処理完了後、Pagesに表示されるURLへアクセスします。

すべて相対パスで参照しているため、プロジェクト用のGitHub Pagesでもそのまま動作します。

## ファイル構成

- `index.html` — ゲーム画面、遊び方、操作ボタン
- `style.css` — レスポンシブレイアウト、盤面と状態の配色
- `script.js` — 5ステージのグラフ定義、入力処理、辺の使用管理、クリア判定
- `README.md` — ゲーム説明と公開手順

ステージは `script.js` の `stages` 配列で管理します。`nodes` は頂点の座標、`edges` は頂点番号（0始まり）のペアです。
